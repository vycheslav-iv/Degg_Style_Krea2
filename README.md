# Degg Style Krea2 — стиль по референсу для Krea 2

Две ноды для ComfyUI, которые переносят **визуальный стиль** картинки-референса на новую генерацию Krea 2:

- **Degg Krea2 · Стиль по референсу** (`DeggKrea2StyleReference`) — только стиль, для генерации по тексту (text2img).
- **Degg Krea2 · Совмещение** (`DeggKrea2StyleFusion`) — стиль плюс целевая картинка как стартовый латент, для переноса стиля на готовое изображение (img2img).

Проект — самостоятельная переделка китайской ноды `krea2-style-refrence`: логика сохранена, интерфейс полностью русский, добавлены локализация, тесты, документация и два примера workflow.

## Честная рамка: что эти ноды делают и чего не делают

Это **не официальный** style-adapter Krea и не патч модели диффузии. Ноды не подмешивают латентные токены референса в UNet и не меняют веса. Работает так:

1. Картинка-референс уменьшается и передаётся в текстовый энкодер Krea 2 (Qwen3-VL) через `clip.tokenize(..., images=[...])`.
2. Qwen3-VL **описывает референс словами** — палитру, материалы, свет, манеру.
3. Это описание вместе с вашим промптом становится позитивным условием (CONDITIONING).
4. Структуру результата задаёт либо пустой латент (Стиль по референсу), либо латент целевой картинки (Совмещение).

Отсюда следствия, которые важно понимать до первого запуска:

- Эффект **семантический**, а не математический. Он сильнее на «общей манере» (цвет, свет, фактура) и слабее на точном копировании подписи или мелкого почерка.
- Референс влияет **через текст**, поэтому формулировка промпта реально меняет результат. Если промпт противоречит референсу, победит то, что точнее описано словами.
- Ноды рассчитаны на **Krea 2** (`CLIPLoader` с типом `krea2`). С SDXL/Flux они не дадут того же эффекта: у тех энкодеров нет зрительного пути Qwen3-VL.

## Установка

Нода лежит в `custom_nodes/Degg_Style_Krea2/`. Скопируйте папку целиком (без `tests/`, `__pycache__/`, `.git/`) в рабочую копию ComfyUI и перезапустите ComfyUI. В исходнике проекта синхронизация выполняется командой из корня бандла:

```bash
python sync.py Degg_Style_Krea2
```

После установки или правки `locales/` **обязателен перезапуск ComfyUI**: переводы читаются один раз при старте.

## Какие модели нужны

Проверено на локальном наборе:

| Роль | Файл | Папка |
|------|------|-------|
| UNet Krea 2 Turbo | `Krea2/krea2_turbo_int8_convrot.safetensors` | `models/diffusion_models/` |
| Текстовый энкодер с зрением | `qwen3vl_4b_fp8_scaled.safetensors` | `models/text_encoders/` |
| VAE | `qwen_image_vae.safetensors` | `models/vae/` |

`CLIPLoader` загружается с типом **`krea2`**. Если выбрать другой тип, `clip.tokenize(..., images=[...])` не примет картинку, и стиль потеряется.

## Нода 1. Стиль по референсу

Входы:

| Вход | Что подавать |
|------|--------------|
| `CLIP (krea2)` | энкодер из `CLIPLoader` с типом `krea2` |
| `Картинка-референс стиля` | изображение, у которого нужен стиль |
| `Промпт` | описание желаемой картинки: сюжет, сцена, детали |
| `Сила стиля` | `light` / `balanced` / `strong` (подписи: Слабый / Сбалансированный / Сильный) |
| `Разрешение зрения, px` | до какого размера сжимать референс перед Qwen3-VL |
| `Своя инструкция стиля` | необязательно; заменяет пресет инструкции |

Выход — один `CONDITIONING` (в интерфейсе «Условие (стиль)»). Его подавайте в `KSampler.positive`; негатив можно получить через `ConditioningZeroOut` от того же условия, как в примере.

Порядок проводов в примере:

```
UNETLoader ──► KSampler.model
CLIPLoader ──► Стиль по референсу.clip
VAELoader  ──► VAEDecode.vae
LoadImage  ──► Стиль по референсу.style_image
Стиль по референсу.conditioning ──► KSampler.positive
Стиль по референсу.conditioning ──► ConditioningZeroOut ──► KSampler.negative
EmptyLatentImage ──► KSampler.latent_image
KSampler ──► VAEDecode ──► SaveImage
```

Для text2img denoise в `KSampler` = **1.0**: стартовый латент пустой, структуру строит только модель.

## Нода 2. Совмещение

Входы те же плюс два обязательных:

| Вход | Что подавать |
|------|--------------|
| `VAE (Krea2)` | `qwen_image_vae.safetensors` |
| `Целевая картинка` | изображение, чью композицию и сюжет сохраняем |

Выходы:

- `CONDITIONING` («Условие (стиль)») — как в первой ноде;
- `LATENT` («Стартовый латент») — целевая картинка, закодированная VAE; подавайте в `KSampler.latent_image`.

Порядок:

```
CLIPLoader ──► Совмещение.clip
VAELoader  ──► Совмещение.vae
LoadImage (стиль) ──► Совмещение.style_image
LoadImage (цель)  ──► Совмещение.target_image
VAELoader ──► VAEDecode.vae
Совмещение.conditioning ──► KSampler.positive
Совмещение.conditioning ──► ConditioningZeroOut ──► KSampler.negative
Совмещение.latent ──► KSampler.latent_image
KSampler ──► VAEDecode ──► SaveImage
```

### Denoise — главный регулятор Совмещения

Denoise в `KSampler` решает, сколько останется от целевой картинки. Ориентиры:

| denoise | Что происходит |
|---------|----------------|
| `0.30–0.40` | почти фотография: меняется в основном цвет и свет, фактура едва заметна |
| `0.45–0.55` | рабочий диапазон: сюжет и поза на месте, стиль референса читается отчётливо |
| `0.60–0.70` | сильная переработка: композиция угадывается, детали перерисовываются |
| `0.75–0.90` | от цели остаётся общая раскладка, стиль доминирует |
| `1.0` | цель фактически игнорируется — это уже text2img, пользуйтесь первой нодой |

В примере стоит `0.55`. Меняйте **сначала denoise**, и только потом «Силу стиля»: это разные рычаги. Denoise — про структуру, сила — про формулировку инструкции.

## Сила стиля: light / balanced / strong

Значение combo — протокол, по-русски подписано как Слабый / Сбалансированный / Сильный. Это **не** параметр сэмплера, а разная формулировка инструкции для Qwen3-VL:

- `light` — «заимствуй только общую палитру, фактуру, свет и ритм, сюжет не копируй»;
- `balanced` — то же плюс явный перенос визуального языка, материалов и манеры;
- `strong` — максимально настойчивый перенос манеры при сохранении сюжета из промпта.

Если нужен свой текст, заполните «Свою инструкцию стиля»: она заменит пресет, а промпт всё равно будет добавлен в конец. Внутренние инструкции намеренно оставлены на английском — так стабильнее для Qwen3-VL, — но свою инструкцию можно писать по-русски.

## Разрешение зрения

`vision_resolution` — не размер генерации. Референс масштабируется так, чтобы его площадь была примерно равна `vision_resolution²`, и в таком виде уходит в Qwen3-VL:

- `256` — быстро и грубо, годится для черновых прогонов;
- `384` — значение по умолчанию, стабильный баланс;
- `512` — больше мелких деталей, медленнее;
- `768–1024` — смысл есть только для очень детальных референсов, время растёт заметно.

Пропорции референса сохраняются, поэтому результат не зависит от того, квадратная картинка или нет.

## Рецепты

**1. Новая картинка в стиле референса.** Первая нода, `light` или `balanced`, `vision_resolution` 384, denoise 1.0. В промпте опишите сюжет; не пересказывайте референс.

**2. Перенести стиль на своё фото.** Вторая нода, denoise `0.45–0.55`, `balanced`. Промпт описывает, что должно получиться, а не что было на фото. Если лицо «поплыло» — снижайте denoise, а не силу.

**3. Серия в одном стиле.** Один и тот же референс и одинаковая инструкция, меняется только промпт и seed. Силу и разрешение зрения не трогайте: это и есть «рецепт стиля».

**4. Референс мешает сюжету.** Поставьте `light` и проверьте, не описывает ли промпт предметы с референса. Часто помогает убрать из промпта лишние детали, а не крутить denoise.

## Частые ошибки

- **Стиль не чувствуется.** `CLIPLoader` не с типом `krea2`, либо референс подан не в `style_image`. Проверьте тип энкодера.
- **Копируется сюжет референса.** Промпт сам его называет, либо сила `strong` на простом промпте. Уберите сюжет из промпта или поставьте `light`.
- **В Совмещении ничего не изменилось.** denoise слишком низкий (`< 0.3`) либо целевая картинка не подключена к `target_image`.
- **В Совмещении потерялась композиция.** denoise слишком высокий; снижайте до `0.45–0.55`.
- **Ошибка формы латента.** Целевая картинка кропится по центру до кратности VAE автоматически; если картинка меньше 8 px по стороне, нода честно падает с сообщением `too small`.
- **Пустой или чуждый стиль при своём тексте.** Своя инструкция полностью заменяет пресет. Если она описывает не стиль, а сюжет, стиль пропадёт.
- **Русские названия не появились.** Не перезапущен ComfyUI после правки `locales/`.
- **Combo показывает английские значения.** Так и должно быть в поле значения; подписи в выпадающем списке переводятся отдельно.

## Локализация

Python — английский источник: имена классов, ключи, tooltip. Русские названия нод, подписи входов, выходов и подсказки лежат в `locales/ru/nodeDefs.json`, английские — в `locales/en/nodeDefs.json`. Язык берётся из `Comfy.Locale`: `ru*` → русский, любой другой → английский.

Значения combo (`light` / `balanced` / `strong`) — протокол: они не переводятся и не подменяются. Русские подписи ставит `web/js/style_krea2.js` через `options.getOptionLabel`, а при смене языка подписи переприменяются по событию `Comfy.Locale.change` без перезапуска. Подмена `options.values` запрещена: Python молча ушёл бы в дефолт.

## Ограничения

- Нода не гарантирует пиксельного совпадения стиля: это описание словами, а не обученный adapter.
- Точный текст и мелкие детали референса не переносятся.
- Скорость зависит от `vision_resolution` и от того, насколько длинное описание построил Qwen3-VL.
- Совмещение кропит цель по центру до кратности VAE — это неизбежно при кодировании в латент.
